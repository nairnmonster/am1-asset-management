Asset Management Application Pages

Home Page

Purpose:
Display all recorded assets.

Functions:
- View assets
- Search assets
- Navigate to create asset page

Create Asset Page

Purpose:
Add new assets.

Fields:
- Asset Name
- Asset Type
- Serial Number
- Assigned User
- Status

Edit Asset Page

Purpose:
Modify existing asset details.

Functions:
- Update asset information
- Save changes

Delete Asset Function

Purpose:
Remove decommissioned assets.

Search Function

Purpose:
Locate assets by asset name.

Results:
- Matching assets displayed
- No results message displayed if asset not found
